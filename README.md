# Ultra Cycling Ride : installateurs

Ce dépôt contient uniquement les installateurs Windows de **Ultra Cycling Ride**,
un simulateur de vélo d'intérieur pour home trainer, à usage personnel.

## Installer l'app

1. Ouvre la [dernière version](https://github.com/haarlon/ucr-releases/releases/latest).
2. Dans « Assets », télécharge le fichier `Ultra-Cycling-Ride-Setup-x.y.z.exe`.
3. Lance-le. Windows affiche peut-être « Windows a protégé votre ordinateur » :
   clique sur **Informations complémentaires**, puis **Exécuter quand même**.
   (L'app n'est pas signée, c'est normal pour un projet personnel.)
4. L'app s'installe toute seule et s'ouvre. Un raccourci est créé sur le bureau.

Ensuite, l'app se met à jour toute seule : elle cherche une nouvelle version à
chaque démarrage et l'installe quand tu la fermes.

Configuration : Windows 10 ou 11, 64 bits.
